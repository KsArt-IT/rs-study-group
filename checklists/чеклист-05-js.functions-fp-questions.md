### 10. Задачи «что выведет»

- [ ] **Чистая или нет**

```js
const addToCart = (cart, item) => { cart.push(item); return cart; };
const cart = [];
const next = addToCart(cart, 'apple');
console.log(cart.length, next === cart);
```

- [ ] **Поверхностная копия**

```js
const state = { user: { name: 'Ann' }, count: 0 };
const copy = { ...state, count: 1 };
copy.user.name = 'Bob';
console.log(state.user.name, state.count);
```

- [ ] **`Object.freeze` и вложенный объект**

```js
'use strict';
const cfg = Object.freeze({ db: { port: 5432 }, mode: 'dev' });
cfg.db.port = 3306;
console.log(cfg.db.port);
cfg.mode = 'prod';
```

- [ ] **`const` и мутация**

```js
const arr = [1, 2];
arr.push(3);
console.log(arr);
arr = [];
```

- [ ] **`sort` мутирует исходный массив**

```js
const prices = [30, 10, 20];
const cheapest = (list) => list.sort((a, b) => a - b)[0];
console.log(cheapest(prices), prices);
```

- [ ] **Порядок `compose` и `pipe`**

```js
const compose = (...fns) => (x) => fns.reduceRight((acc, fn) => fn(acc), x);
const pipe = (...fns) => (x) => fns.reduce((acc, fn) => fn(acc), x);
const inc = (x) => x + 1;
const double = (x) => x * 2;
console.log(compose(inc, double)(5), pipe(inc, double)(5));
```

- [ ] **Каррирование и параметр по умолчанию**

```js
const curry = (fn) => function c(...a) { return a.length >= fn.length ? fn(...a) : (...b) => c(...a, ...b); };
const add = curry((a, b = 10, c) => a + b + (c ?? 0));
console.log(add.length, typeof add(1), add(1));
```

- [ ] **`map(parseInt)`**

```js
console.log(['10', '10', '10'].map(parseInt));
```

- [ ] **Мемоизация нечистой функции**

```js
let rate = 2;
const memo = (fn) => { const c = new Map(); return (x) => (c.has(x) ? c.get(x) : (c.set(x, fn(x)), c.get(x))); };
const convert = memo((x) => x * rate);
console.log(convert(10));
rate = 3;
console.log(convert(10));
```

- [ ] **Замыкание в фабрике функций**

