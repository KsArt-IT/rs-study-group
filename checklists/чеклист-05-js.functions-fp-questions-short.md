### 10. Задачи «что выведет»

- [ ] **Чистая или нет**

```js
const addToCart = (cart, item) => { cart.push(item); return cart; };
const cart = [];
const next = addToCart(cart, 'apple');
console.log(cart.length, next === cart);
```

- [ ] **Поверхностная копия**

```js
const state = { user: { name: 'Ann' }, count: 0 };
const copy = { ...state, count: 1 };
copy.user.name = 'Bob';
console.log(state.user.name, state.count);
```

- [ ] **`Object.freeze` и вложенный объект**

```js
'use strict';
const cfg = Object.freeze({ db: { port: 5432 }, mode: 'dev' });
cfg.db.port = 3306;
console.log(cfg.db.port);
cfg.mode = 'prod';
```

- [ ] **`sort` мутирует исходный массив**

```js
const prices = [30, 10, 20];
const cheapest = (list) => list.sort((a, b) => a - b)[0];
console.log(cheapest(prices), prices);
```
