### 13. Задачи «что выведет»

Код выполняется в ES-модуле (strict mode).

- [ ] **Потеря контекста**

```js
const user = { name: 'Ann', hi() { return this.name; } };
const hi = user.hi;
user.hi(); // ?
hi();      // ?
```

- [ ] **Стрелочная функция как метод**

```js
const obj = { name: 'Obj', arrow: () => this, regular() { return this.name; } };
obj.arrow();   // ?
obj.regular(); // ?
```

- [ ] **Затенение свойства прототипа**

```js
function Rabbit() {}
Rabbit.prototype.teeth = 'small';
const r = new Rabbit();
r.teeth = 'long';
r.teeth;                  // ?
new Rabbit().teeth;       // ?
Object.hasOwn(r, 'teeth'); // ?
```

- [ ] **Массив в прототипе**

```js
function Cart() {}
Cart.prototype.items = [];
const a = new Cart();
const b = new Cart();
a.items.push('x');
b.items; // ?
```

- [ ] **Класс до объявления и без `new`**

```js
new Foo(); // ?
class Foo {}
class Bar {}
Bar();     // ?
```

- [ ] **Конструктор возвращает значение**

```js
function P() { this.a = 1; return { b: 2 }; }
function Q() { this.a = 1; return 5; }
new P(); // ?
new Q(); // ?
```

- [ ] **`instanceof` после замены прототипа**

```js
function A() {}
const x = new A();
A.prototype = {};
x instanceof A; // ?
```

- [ ] **`this` до `super()`**

```js
class Base { constructor() { this.v = 1; } }
class Child extends Base {
  constructor() {
    this.w = 2;
    super();
  }
}
new Child(); // ?
```

- [ ] **Приватные поля**

```js
class C {
  #secret = 1;
  get secret() { return this.#secret; }
  static has(obj) { return #secret in obj; }
}
const c = new C();
c.secret;            // ?
Object.keys(c);      // ?
JSON.stringify(c);   // ?
C.has(c), C.has({}); // ?
```

- [ ] **Метод vs стрелочное поле**

```js
class M { method() {} arrow = () => {}; }
const m1 = new M();
const m2 = new M();
m1.method === m2.method; // ?
m1.arrow === m2.arrow;   // ?
Object.keys(m1);         // ?
```

- [ ] **Класс — это функция**

```js
class K { m() {} }
typeof K;                              // ?
Object.keys(K.prototype);              // ?
Object.getOwnPropertyNames(K.prototype); // ?
```

### 14. Задачи «реализуйте»

- [ ] **Наследование на функциях-конструкторах (без `class`)**

Есть `Animal(name)` с методом `speak()` в прототипе. Сделайте `Cat`, который наследует `Animal` и переопределяет `speak()`, вызывая родительскую версию. Без `class` и `extends`.

- [ ] **Свой оператор `new`**

Напишите `myNew(Ctor, ...args)`, который повторяет поведение `new Ctor(...args)`, включая случай, когда конструктор возвращает объект.

- [ ] **Свой `instanceof`**

Напишите `myInstanceOf(obj, Ctor)`, который работает как `obj instanceof Ctor`.

- [ ] **Абстрактный класс и полиморфизм**

Сделайте класс `Shape`, экземпляр которого нельзя создать напрямую, с «абстрактным» методом `area()`, и наследника `Square`.

- [ ] **Инкапсуляция: геттер, сеттер и статическая фабрика**

Класс `Temperature` хранит температуру в градусах Цельсия в приватном поле, а наружу отдаёт свойство `fahrenheit` (чтение и запись) и фабрику `Temperature.fromFahrenheit()`.

- [ ] **Миксин**

Напишите миксин `Serializable`, который добавляет любому классу метод `toJSON()`, возвращающий поля объекта и имя класса в поле `type`.

- [ ] **Свой класс ошибки**

Создайте `NotFoundError`, который наследует `Error`, проходит проверку `instanceof` и при выводе показывает своё имя.
