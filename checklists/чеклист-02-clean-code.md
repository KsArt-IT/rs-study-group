# Clean Code + линтеры, форматтеры, Husky: вопросы к собеседованию и тестам

Записано 2026-10-21.

**Как устроен файл**
- Новое понятие сначала вводится вопросом «что такое…», потом идут вопросы, которые его раскрывают и применяют.
  Ни один вопрос не опирается на термин, который ещё не определён выше.
- Внутри раздела сначала **Теория**, потом **Практика**.
- Сложность: 🟢 база (Junior, тест) · 🟡 понимание (уверенный Junior) · 🔴 рассуждение (Middle, «а почему?»).
- Отмечай `[x]`, если ответил вслух своими словами без подсказки, `[~]` — с подсказкой.
  Кивок не считается.
