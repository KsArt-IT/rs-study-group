### 10. Задачи: что выдаст компилятор

- [ ] **Есть ли ошибка?**

```ts
interface Point { x: number; y: number }
const p = { x: 1, y: 2, z: 3 };
const a: Point = p;
const b: Point = { x: 1, y: 2, z: 3 };
```

- [ ] **Какой тип у `method` и почему вызов не компилируется?**

```ts
const req = { url: '/api', method: 'GET' };
declare function send(url: string, method: 'GET' | 'POST'): void;
send(req.url, req.method);
```

- [ ] **Какие типы у `A`, `B`, `C`?**

```ts
type ToArray<T> = T extends any ? T[] : never;
type A = ToArray<string | number>;
type B = [string | number] extends [any] ? (string | number)[] : never;
type C = keyof { [k: string]: boolean };
```

- [ ] **Есть ли ошибка?**

```ts
function len(s: string): number;
function len(arr: unknown[]): number;
function len(x: any) { return x.length; }

len(Math.random() > 0.5 ? 'hi' : [1]);
```

- [ ] **Что выдаст компилятор?**

```ts
class Account {
  private balance = 0;
  #pin = '1234';
}
const acc = new Account();
console.log(acc['balance']);
console.log(acc.balance);
```

- [ ] **Какой тип у `IsNever<never>`?**

```ts
type IsNever<T> = T extends never ? true : false;
type R = IsNever<never>;
```

- [ ] **Есть ли ошибка?**

```ts
function makeDefault<T extends { id: number }>(): T {
  return { id: 0 };
}
```

- [ ] **Где ошибка и как исправить?**

```ts
function f(user: { name: string | null }) {
  if (user.name !== null) {
    setTimeout(() => console.log(user.name.length));
  }
}
```

- [ ] **Есть ли ошибка?**

```ts
type Cb = () => void;
const cb: Cb = () => 42;
const r = cb();

function f(): void {
  return 42;
}
```

- [ ] **Есть ли ошибка?**

```ts
function sortInPlace(arr: number[]) {
  arr.sort();
}
const nums: readonly number[] = [3, 1, 2];
sortInPlace(nums);
```

- [ ] **В какой строке ошибка?**

```ts
interface Handlers {
  method(x: string | number): void;
  prop: (x: string | number) => void;
}
const onlyString = (x: string) => {};
const h: Handlers = { method: onlyString, prop: onlyString };
```
